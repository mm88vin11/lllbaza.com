# lllbaza.ru

Сайт студии БАЗА: одна страница, собранная из исходника и медиа.

## Собрать

```sh
node build/build.mjs      # index.html + кадры в public/media/  ← так публикуем
node build/pages.mjs      # 404, 500 и «спасибо»
node build/dist.mjs       # всё, что уходит на хостинг → dist/
```

Одной строкой: `node build/build.mjs && node build/pages.mjs && node build/dist.mjs`

Публикуется папка `dist/`. Она же настроена в `netlify.toml`.

### Второй режим: один файл

```sh
node build/build.mjs --inline
```

Кладёт кадры обратно внутрь `index.html` — получается 20 МБ, зато файл
открывается с диска, без сервера. Для отправки «посмотри, как выглядит» это
удобно, для публикации — нет: браузер обязан выкачать все 20 МБ прежде, чем
покажет первый экран.

## Что где лежит

| Путь | Что это |
|---|---|
| `src/page.html` | Единственный файл, который правим руками: разметка, стили, компонент |
| `src/assets/media/` | Кадры заставки, картинки ленты, логотипы |
| `src/assets/runtime.json` | Копии React — встраиваются в страницу всегда |
| `build/` | Сборка: страница, служебные страницы, dist, адрес обработчика заявок |
| `public/` | Статика: иконки, og, robots, sitemap, llms.txt, заголовки, редиректы |
| `server/` | Обработчик заявок (Cloudflare Worker) |
| `index.html`, `dist/` | Результат сборки |

`public/media/` собирается из `src/assets/media/` и в git не хранится.

## Куда уходят заявки

Браузер знает только адрес обработчика. Токен бота живёт в секретах воркера и
в страницу не попадает.

```sh
cd server
npx wrangler deploy
npx wrangler secret put TG_TOKEN     # токен бота от @BotFather
npx wrangler secret put TG_CHAT      # id чата, куда писать

cd ..
node build/set-lead.mjs https://lead.lllbaza.ru/
node build/build.mjs
```

Пока адрес не задан, форма работает, но заявка только сохраняется в браузере
посетителя и предлагает продублировать её в Telegram — интерфейс говорит об
этом честно, не делая вид, что письмо ушло.
