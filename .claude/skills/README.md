# Скиллы, подключённые к проекту

Здесь лежат наборы правил, по которым мы правим дизайн и интерфейс. Они
поставлены из сторонних репозиториев по просьбе владельца проекта; лицензии
и авторство — внутри каждой папки.

| Папка | Откуда | Зачем здесь |
|---|---|---|
| `ui-ux-pro-max`, `design`, `design-system`, `brand`, `ui-styling`, `banner-design`, `slides` | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | Каталоги шрифтов, иконок и приёмов вёрстки, чек-листы по UI |
| `taste-skill`, `brandkit`, `minimalist-skill`, `brutalist-skill`, `soft-skill`, `redesign-skill`, `output-skill`, `stitch-skill`, `image-to-code-skill` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | Правила вкуса: типографика, ритм, отказ от шаблонных решений |
| `impeccable` | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | Придирчивый разбор макета: отступы, состояния, мелочи |
| `motion-fix`, `motion-improve` | [motiondivision/motion](https://github.com/motiondivision/motion) | Правила анимации: что анимировать, чем и как долго |

Отдельно, без папки: [«Музей AI-слопа»](https://ai-slop.matvei-vibecoder.com/) —
список из 40 признаков «сайта, который делала нейросеть». Применён как
стоп-лист: на странице нет фиолетово-синих градиентов, градиентного текста,
Playfair Display, глассморфизма ради глассморфизма, bento-сеток, эмодзи
вместо иконок, «нам доверяют» с чужими логотипами и выдуманных отзывов.
